# Identidade visual — Olokuti Digital

## Conceito

MVP acadêmico de catálogo, tarefas e organização operacional com Django e PostgreSQL.

## Paleta

| Token | Cor | Uso |
| --- | --- | --- |
| Base | `#092B2A` | Fundo principal |
| Primária | `#0F766E` | Elementos de marca |
| Destaque | `#A3E635` | Ênfase e contraste |

## Arquivos

- `logo.svg`: símbolo vetorial.
- `banner.svg`: banner horizontal para README e materiais do projeto.
- `project-mark.svg`: marca compacta legada, preservada para compatibilidade.

## Uso

Preserve proporções, cores e área de respiro. Não aplicar sombras ou efeitos externos sem necessidade. A marca deve permanecer legível em fundos escuros.
